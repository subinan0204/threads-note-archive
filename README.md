# Threads Note PWA

정적 파일 PWA. HTTPS 호스팅이 필요합니다 (GitHub Pages/Cloudflare Pages 등). 게시물/대화/팔로워 데이터는 브라우저 IndexedDB에 저장하고, 토큰은 sessionStorage에만 보관합니다.

## Meta 연결
Meta 개발자 대시보드에서 Threads API 앱과 권한을 구성하고 장기 사용자 토큰을 발급한 다음 앱 설정에 붙여넣습니다. 필요한 권한: `threads_basic`, `threads_manage_insights`, 답글/대화 수집용 `threads_read_replies`. 앱 시크릿을 프런트엔드에 넣지 마세요. 장기 토큰은 약 60일 유효하며, 갱신은 공식 `refresh_access_token` 요청을 사용합니다.

## 기능 및 제한
- 달력, 기간/지표별 TOP 50, 단어 빈도와 검색/하이라이트, 제한 범위의 소통 데이터, 팔로워 스냅샷/그래프, JSON 백업/복원, 샘플 보기
- 최초 게시물은 `/{user-id}/threads` 페이지네이션으로 수집하고, 이후 마지막 동기화 시점 이후 증분 수집. 인사이트는 회당 최대 25개를 점진적으로 처리해 요청량을 제한
- 앱 내 메뉴 이동은 브라우저 뒤로 가기와 연동
- 게시물 대화는 상세에서 선택 조회, 내 답글은 별도 API에서 조회. 순위는 접근 가능한 API 데이터만 사용하며 전체 상호작용을 보장하지 않음
- OAuth 리디렉션과 서버 측 코드 교환은 미구현. 브라우저 토큰 방식은 개인 전용 사용에만 권장하고, 브라우저 세션에서 요청됨. 직접 API 호출은 CORS/Meta 앱 승인/실제 계정 상황에 따라 실패할 수 있음
- 한국어 형태소 분석, 조사·어미 통합, 2단어 조합, 월별 키워드 비교, 댓글 계층 전체 보기, 백엔드 프록시/자동 OAuth는 미구현
- 실제 Threads 계정으로 API 연결 검증 전. 샘플은 명시적으로 표시

## PWA
HTTPS에서 제공하면 앱 설치와 서비스워커 오프라인 셸 캐시가 동작합니다. 앱 셸 업데이트는 캐시 버전 교체, 데이터는 IndexedDB에 남습니다. `file://`로 직접 열면 PWA 설치/서비스워커를 사용할 수 없습니다.
